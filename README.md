# 🧠 Dr. Ronny OS Phoenix

**Das Smart-Home Control Center für Home Assistant – entwickelt für Menschen, die mehr wollen als nur einzelne Geräte zu verwalten.**

Dr. Ronny OS Phoenix bündelt zentrale Home-Assistant-Funktionen in einer modernen, übersichtlichen Oberfläche und erweitert sie um intelligente Verwaltungs- und Analysefunktionen.

> 🚀 **Aktuelle stabile Version: 1.0.31**

---

## ✨ Warum Dr. Ronny OS Phoenix?

Home Assistant ist extrem leistungsfähig – aber bei vielen Geräten, Entitäten, Bereichen, Labels, Skripten und Automationen kann die Verwaltung schnell unübersichtlich werden.

**Phoenix bringt Ordnung hinein.**

Statt sich durch viele einzelne Bereiche zu klicken, bietet Phoenix ein zentrales Control Center für die tägliche Arbeit mit Home Assistant.

### 🧠 Ronny AI

Phoenix enthält mit **Ronny AI** eine intelligente Unterstützung für die Home-Assistant-Verwaltung.

Unter anderem können Geräte und ihre Zuordnung analysiert werden, um sinnvolle **Bereichsvorschläge** zu erkennen und Verwaltungsaufgaben einfacher zu machen.

## 🚀 Installation

Dr. Ronny OS Phoenix wird als **Home-Assistant-Add-on** über das offizielle Dr. Ronny OS Add-on-Repository bereitgestellt.

### 1. Repository hinzufügen

In Home Assistant:

**Einstellungen → Add-ons → Add-on Store → ⋮ → Repositories**

Repository eintragen:

`https://github.com/FairestDoc2/dr-ronny-os-apps`

Danach das Repository hinzufügen.

### 2. Phoenix installieren

Im Add-on Store erscheint anschließend:

**🧠 Dr. Ronny OS Phoenix**

Add-on öffnen → **Installieren**

### 3. Starten

Nach der Installation:

**Starten → In der Seitenleiste anzeigen**

Phoenix ist anschließend direkt über die Home-Assistant-Oberfläche erreichbar.
