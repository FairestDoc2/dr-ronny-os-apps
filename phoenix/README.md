# 🧠 Dr. Ronny OS Phoenix

**Dr. Ronny OS Phoenix** ist ein lokales Smart-Home Control Center
für Home Assistant.

Phoenix erweitert Home Assistant um eine zentrale Oberfläche für
Verwaltung, Kontrolle, Automatisierung und KI-Unterstützung.

## Funktionen

- 🏠 Home-Assistant-Systemübersicht
- 🧠 Ronny AI
- 🔌 Entitätenverwaltung
- 💡 Geräteverwaltung
- 📍 Bereichsverwaltung
- 🏷️ Label-Verwaltung
- ⚡ Automationen
- 📜 Skripte mit dynamischen Home-Assistant-Servicefeldern
- 🧠 Phoenix / OS-Snapshots
- 🏠 native Home-Assistant-Backups
- 🌍 mehrsprachige Benutzeroberfläche
- 🔐 lokale Ausführung innerhalb von Home Assistant

## Ziel

Phoenix soll die alltägliche Verwaltung von Home Assistant
verständlicher, übersichtlicher und komfortabler machen,
ohne wichtige Funktionen von Home Assistant zu ersetzen.
